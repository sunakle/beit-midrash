# Бейт Мидраш

Сайт для чтения и изучения иудаизма на основе предоставленной библиотеки.

- 20 книг, 9 492 страницы.
- 12 вводных уроков, 36 вопросов с пояснениями.
- Читалка с увеличением, переходом к странице, закладками и заметками.
- Поиск по названиям и по имеющемуся текстовому слою внутри книги.
- Прогресс, лучшие результаты тестов, экспорт и импорт личных данных.
- Адаптивный интерфейс для компьютера и телефона.

## Открыть на компьютере

Запустите **Открыть сайт.cmd**. Требуется Python, уже установленный на компьютере владельца. Откроется http://127.0.0.1:8765. Окно сервера должно оставаться открытым; Ctrl+C завершает работу. Если порт занят уже открытым просмотром, используйте эту же ссылку.

Можно также открыть `index.html` двойным щелчком: библиотека, изображения, уроки и тесты работают без сервера. Поиск по тексту требует запуска через сервер. Прогресс у локального файла и сайта по HTTP хранится отдельно.

## GitHub Pages

Файлы подготовлены для публичного репозитория `beit-midrash`. Рабочий процесс `.github/workflows/pages.yml` проверяет полноту библиотеки и публикует сайт при отправке изменений в ветку `main`.

В настройках репозитория **Settings → Pages → Source** выберите **GitHub Actions**. После успешной публикации адрес будет показан в выполненном процессе публикации. Учётная запись GitHub должна быть подключена; эти файлы сами по себе не означают, что сайт опубликован.

## Проверка

`node verify.mjs` проверяет все страницы, количество книг, ссылки уроков на источники и структуру тестов. Нет сборки и обязательных npm-зависимостей. Навигация по хеш-ссылкам и относительные пути поддерживают размещение в подпапке GitHub Pages.

## Материалы

Все страницы 20 исходных PDF преобразованы в PNG. Первые пять страниц каждого файла сохранены в цвете; остальные подготовлены как контрастные чёрно-белые страницы шириной 1600 пикселей. Это облегчённая версия для чтения, не архивная копия PDF. Оригиналы в исходной папке не изменены. Три DJVU-файла представлены PDF-версиями изданий с соответствующими названиями, без отдельного дублирования в каталоге.

Готовый текстовый слой извлечён из PDF без нового OCR. В книгах-сканах доступно чтение изображений. Порядок строк и распознавание иврита в имеющемся текстовом слое могут содержать ошибки; сверяйте со сканом. Номер страницы сайта соответствует странице файла, а не обязательно печатному номеру.

Уроки являются отдельным вводным изложением по указанным страницам, а не полным курсом по каждому тому. Выходные данные издательств, переводы и комментарии сохранены на страницах книг. Прохождение тестов не является религиозной квалификацией или гиюром.

## Личные данные

Все заметки, закладки и результаты сохраняются в localStorage текущего браузера. Учётных записей и серверной синхронизации нет. Для переноса используйте экспорт/импорт. Внешние Google Fonts имеют системные запасные шрифты.
